# Security policy

## Reporting a problem

Please don't report security problems in a public issue. Use GitHub's private vulnerability reporting instead:
**Security** tab of this repository → **Report a vulnerability**. You'll get an answer as soon as I can manage; this is
a one-person fan project.

Useful in a report: the Glide version (the app's footer, or `desktop/package.json`), what an attacker can do, and the
steps to reproduce it.

## Supported versions

Only the latest release gets fixes. Glide updates itself, so a fix reaches players with the next release.

## What counts

Anything that lets another program, web page, network peer or community-feed entry make Glide do something the player
didn't ask for: read or send API keys, run code, write files outside Glide's own folders, or reach the engine's local
server. Problems in the game itself, or in RestedXP, belong to their own projects.
